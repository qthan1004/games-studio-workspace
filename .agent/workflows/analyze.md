# Requirement analysis and design

Read the active repository's preflight, or `<workspace>/.agent/PREFLIGHT.md` for workspace tasks. Use the relevant skills from `<workspace>/.agent/`:

- `analyze-requirements/SKILL.md`: ground the requested result in evidence and testable acceptance criteria.
- `interview-me/SKILL.md`: resolve a material product decision that remains after investigation; wait for its answer before the dependent edit.
- `spec-driven-development/SKILL.md`: produce a requested or necessary shared specification.
- `planning-and-task-breakdown/SKILL.md`: produce a requested implementation plan.

Load only the needed skills. Do not force a confidence score, full three-phase pipeline, or repeated user approval. Follow existing authorization and explicit review checkpoints. Analysis alone does not authorize implementation.

Present the result in conversation unless the user requests a file or the task needs a durable artifact. Follow workspace/repository placement rules.
